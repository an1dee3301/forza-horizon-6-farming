# FH6 Wheelspin reward car catalog

This data pull contains 442 cars whose Collection field on Forza's official FH6 car list includes `Wheelspin`. That field is the source classification for wheelspin eligibility in the game.

- Source: https://forza.net/fh6cars
- Source page updated: 2026-09-08
- Extracted: 2026-09-24
- Files: `cars.json` (full records and extraction metadata), `cars.csv` (tabular copy), and `car-names.txt` (all display names, one per line).

The Fandom `Wheelspin Reward (FH6)` category was observed to advertise 449 items. That differs by seven from the official Collection-field filter; the Fandom page's full listing could not be retrieved during extraction, so this catalog uses the official list and does not claim to reconcile those seven entries.

This is an eligibility catalog only. It does not define the account's protected-car list or imply that every listed car should be retained.

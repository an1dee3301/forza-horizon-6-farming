The shortcut applies only when a fresh Recently Added / All Cars frame proves focus on the second-row first-column card and the exact NEW Mad Mike card immediately above. It sends one Up, then requires a newer image proving first-card focus and identity before normal car-entry checks. A known unchanged garage falls back to the original Jump; it never repeats Up. Other states retain normal recovery.

This saves about 1.5–1.7 seconds on eligible selections. Whole trial cycle active durations were 65.031 and 57.219 seconds; variable game loading still dominates. These observations do not establish a whole-cycle causal improvement or 33 saved Super Wheelspins/hour.

# Menu focus stage evidence

Two live trials per stage used the same exact target and reward proofs while replacing programmed pacing with fresh focus observations.

| Stage | Trial durations | Trial median | Comparison median |
| --- | --- | --- | --- |
| Mastery | 8.266s, 7.829s | 8.0475s | 9.5315s |
| Return | 11.204s, 11.766s | 11.485s | 12.281s |

These are non-randomized stage comparisons from a private runtime. That runtime used a fixed 0.35s mastery movement wait and 0.30s return confirmation wait. The public checkout had different pacing (0.07s mastery movement and immediate focused confirmation), so this evidence does **not** establish a speed gain against the public checkout.

Mastery polling leaves three fresh exact-selection proofs, three ownership proofs, and one Enter per reward intact. Return polling covers only Master Explorer and Car Collection confirmation; it does not accelerate arrows or send Enter itself. Synchronous capture can finish after a polling deadline; elapsed time includes that work. A late capture cannot authorize a successful early handoff.

This is not native saved-Super-Wheelspin throughput qualification. All failures, retries, farming, conversion, cleanup, and restart time remain part of complete rate windows. Two passing windows of at least 100 new saved Super Wheelspins have not been established by these stage trials.
